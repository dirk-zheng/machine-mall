# Vendora Systems

Vendora 是一个面向品牌方、自动售卖机运营商、办公园区、学校、医院和物业公司的 B2B 自动售卖机定制平台。

## 核心能力

- 零食饮料、鲜食冷藏、冷冻、咖啡、工业 PPE 和专业零售机型
- OEM / ODM 柜体、外观、货道、制冷和出货结构定制
- 银行卡、移动钱包、二维码、现金、会员和员工身份识别
- 远程库存、销售、温度、故障和内容管理
- 公开定制询盘、登录 RFQ、在线客服和后台内容管理

## 本地开发

```bash
npm run install:all
npm run dev
npm run dev:server
```

前端默认地址：`http://localhost:5173/`

后端默认地址：`http://localhost:3001/`

## 生产构建

```bash
npm run build
```

Ubuntu 部署说明见 [DEPLOY-UBUNTU.md](./DEPLOY-UBUNTU.md)。
